# README media policy

The public README should show **real, reproducible product images**.

## Allowed

- Screenshots captured from a verified build.
- Theme previews recovered from the canonical source package.
- Project-owned branding artwork.
- Diagrams that are clearly diagrams rather than screenshots.

## Not allowed

- Fabricated screenshots presented as the running application.
- Broken image links.
- Images copied from unrelated desktop customizers.
- Vendor-owned artwork presented as project-owned UI.
- Screenshots from an unknown build/version without labeling.

## Restoration checklist

- [ ] Recover canonical source package.
- [ ] Confirm version.
- [ ] Build graphical application.
- [ ] Capture representative screenshots.
- [ ] Restore verified theme previews.
- [ ] Add captions/environment where useful.
- [ ] Add social-preview image only after the visual identity is verified.

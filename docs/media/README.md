# README media policy

Public project media must come from a known, reproducible build of the version it describes. Record the source commit/version used to produce it.

## Allowed

- Screenshots captured from a verified build.
- Theme previews recovered from canonical source.
- Project-owned branding artwork.
- Diagrams clearly labelled as diagrams rather than application screenshots.

## Not allowed

- Fabricated screenshots presented as the running application.
- Broken image links.
- Images copied from unrelated desktop customizers.
- Vendor-owned artwork presented as project-owned UI.
- Screenshots from an unknown build/version without labelling.
- Mockups used as evidence that a feature is implemented.

## Restoration checklist

- [ ] Recover canonical source.
- [ ] Confirm the represented version.
- [ ] Build the graphical application reproducibly.
- [ ] Capture representative screenshots.
- [ ] Restore verified theme previews.
- [ ] Add captions and desktop-environment context where useful.
- [ ] Add social-preview artwork only after the visual identity is verified.
